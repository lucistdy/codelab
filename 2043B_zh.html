数字谜题：破解重复阶乘次的超长数字

Artem 在黑板上写下同一个数字 d，一连写了整整 n! （n 的阶乘）次。哪怕 n 只有 8，那也已经是 40,320 个数字了——而 n 最大能到 10 亿。Codeforces 2043B 问的是：奇数数字 1、3、5、7、9 里，哪些能整除这个庞然大物？你永远不可能真的把这个数造出来——但你可以靠动脑子取胜。

写给爱思考的 13 岁少年 结合"神奇的5"与"回声机器" 可互动
第一关

认识这个任务

给你一个数字 d（1 到 9 之间）和一个数字 n。Artem 把 d 连续写了 n!（"n 的阶乘"）次，组成一个超级长、从头到尾全是数字 d 的巨大数字。回忆一下，n! = 1 × 2 × 3 × … × n——它增长得快到令人难以置信。

你的任务：找出奇数数字——1, 3, 5, 7, 9——里哪些能整除这个庞大的数字，并按从小到大输出。一次运行里可能会问你多达 100 组不同的 (n, d)。

题目原话

n=2, d=6 → 黑板上是 66（因为 2! = 2）。1 3 能整除它（66 = 2×3×11）。
n=7, d=1 → 黑板上是 111…1，一共 7! = 5040 个 1。1 3 7 9 能整除它。
n=8, d=5 → 黑板上是 555…5，一共 8! = 40320 个 5。1 3 5 7 9——每一个奇数数字都能整除它！

为什么要在意速度？

n 最大可以到 1,000,000,000（10 亿）。哪怕 n 只是一个不算大的数，n! 就已经是个怪物了：20! 就有 19 位数字，而 n 达到十亿量级时，n! 会有几十亿甚至更多位数字。你根本没法把这个数存下来，更别说在 1 秒内一位一位去检查了。

第二关

先把整除判断的工具箱翻出来

在动手对付这个巨大数字之前，先回忆一下我们已经会的、不用做除法就能判断整除的小技巧：

  • 能被 1 整除：永远成立。任何数都能被 1 整除——白送一分！
  • 能被 5 整除：当且仅当最后一位是 0 或 5。这正是我们在神奇的 5那一页用过的思路。
  • 能被 3 或 9 整除：把所有数字加起来。如果这个和能被 3（或 9）整除，那原来的数也能。
  • 能被 7 整除：……7 没有那种巧妙的"数字和"捷径。我们得用另一种技巧，而这正是这道题最有意思的部分。

第三关

为什么"真的把数造出来"行不通

最直接的想法是：算出 n!，把 d 写那么多次，然后直接检查能不能整除。对于很小的 n，这完全没问题——但 n 最大能到十亿，而 n! 增长的速度比 n 本身快得多得多。地球上所有计算机的存储空间加在一起，都装不下这么多位数字的数，更别提在 1 秒内一位一位扫一遍了。

第四关

数字 5：我们早就顺手解决的免费题

这个巨大数字的每一位都是 d——包括最后一位。所以整个数的最后一位，就是 d 本身。用第二关的规则：能被 5 整除，当且仅当 d = 5。就这么简单——这一项完全不需要涉及任何阶乘计算！

最重要的一句话

答案里有没有 5，只取决于 d == 5 是否成立。不管 n 是多少，永远如此。

第五关

数字 3 和 9：被 n! 加成的数字和技巧

这个巨大数字的数字和很好算：它是 d 重复了 n! 次，所以数字和就是 d × n!。根据第二关：能被 3 整除当且仅当 3 | (d × n!)，能被 9 整除当且仅当 9 | (d × n!)。

精彩的地方在这里：阶乘会自动"攒"出 3 的因子。一旦 n ≥ 3，乘积 n! = 1×2×3×…×n 里就已经包含数字 3 本身作为其中一个因子——所以 3 | n!，这意味着不管 d 是多少，3 | (d × n!) 都成立。而对于 9，我们需要 n! 里藏着两个 3 的因子（因为 9 = 3×3）——这一点要等到 n ≥ 6 才第一次成立，因为 6! 是第一个同时包含因子 3和因子 6（本身也是 3 的倍数）的阶乘。

nn!n! 内部藏着几个 33 | n! ?9 | n! ?

从 n=6 开始，n! 永远至少藏着 2 个 3 的因子，之后 9 | n! 一直成立。

所以：当 n ≥ 3 时，不管 d 是多少，数字 3 都能整除这个数。当 n ≥ 6 时，不管 d 是多少，数字 9 也能整除。只有剩下的几个小情况（数字 9 在 n = 3, 4, 5 时）才真的取决于 d。

是不是很眼熟？10 的各次幂，对 7 取余数，每 6 步就会回声一次——这和Jzzhu 的回声机器那一页里数列"永远回声"的脾气一模一样，只不过换了一套数字来演。这个周期为 6 的回声，正是数字 7 这道题的全部秘密。

为什么这很重要？一段由 m 个重复数字组成的块，可以写成 d × Rm，其中 Rm 是"连续 1"数字 111…1（共 m 个 1）。可以证明，7 | Rm 当且仅当 6 | m——这正是周期为 6 的回声带来的直接结果。而且，就像第五关里因子 3 那样，只要 n ≥ 3，阶乘 n! 就已经同时包含一个因子 2和一个因子 3，二者合起来就能保证 6 | n!。所以当 n ≥ 3 时，m = n! 自动就是 6 的倍数，回声正好落回 1，于是不管 d 是多少，7 都能整除这个数。

第七关

汇总起来：大 n 情况下的一条简洁规则

把我们发现的一切汇总一下。每个数字"不再依赖 d"的临界点是：3 和 7 在 n ≥ 3 时就锁定了，9 要等到 n ≥ 6 才锁定。一旦 n ≥ 6，三个临界点全部越过，我们就得到一条极其简洁的规则：

最重要的一句话

当 n ≥ 6 时：答案永远是 {1, 3, 7, 9}，再加上 d = 5 时额外多一个 5。此时 d 取什么值，压根不影响答案！

这样一来，只剩下 n = 2, 3, 4, 5 这几个特殊情况了——而有趣的转折在这里：这几个数对应的阶乘分别是 2, 6, 24, 和 120。全都小得很！对付这几个特殊情况根本不需要任何巧思——直接把真正的数字造出来（最多 120 位，对 Python 内置的大整数来说小菜一碟），然后老老实实检查整除就行。

第八关

逐行读代码

下面是完整的解法。先看左边的代码，再看右边的大白话翻译。

digits.py
import math

def solve(n, d):
    if n >= 6:
        divisors = {1, 3, 7, 9}
        if d == 5:
            divisors.add(5)
    else:
        m = math.factorial(n)          # n < 6，所以 m 最多是 120——非常小！
        number = int(str(d) * m)     # 真的把这个数造出来
        divisors = {x for x in [1,3,5,7,9] if number % x == 0}
    return sorted(divisors)

t = int(input())
for _ in range(t):
    n, d = map(int, input().split())
    print(*solve(n, d))
if n >= 6: divisors = {1, 3, 7, 9} if d == 5: divisors.add(5)

第十一关

练习题：先自己算，再用工具核对

每一题都先在纸上算一遍，再用上面的小工具验证答案。

练习 1：n=2, d=9。黑板上是 "99"。哪些奇数数字能整除它？

99 = 9 × 11。逐个检查：99/1=99 是，99/3=33 是，99/5=19.8 否，99/7≈14.14 否，99/9=11 是。答案：1 3 9。

练习 2：n=3, d=2。不用把数造出来，说明为什么 3 和 7 必然整除它，而 9 不行。

因为 n=3 ≥ 3，第五关和第六关里"3 锁定"和"7 锁定"的临界点都已经越过了，所以不管 d 是多少，3 和 7 都能整除这个数。但 n=3 < 6，所以 9 不是自动成立的——它需要 d 是 3 的倍数，而 d=2 不是。黑板上是 222222（6 个 2，因为 3!=6）：数字和是 12（能被 3 整除，不能被 9 整除），验证了 1 3 7，没有 9。

练习 3：n=5, d=6。哪些奇数数字能整除黑板上的数？

n=5 ≥ 3 已经锁定了 3 和 7。对于 9，我们需要 n ≥ 6 或者 d 是 3 的倍数——这里 n=5 < 6，但 d=6 确实是 3 的倍数，所以 9 也能整除！对于 5，需要 d=5，而 d=6≠5，所以没有 5。答案：1 3 7 9。

练习 4（挑战题）：n=1,000,000,000, d=5。这个数显然造不出来——用第七关的捷径求出答案。

n ≥ 6，所以答案自动是 {1, 3, 7, 9}，又因为 d = 5，还要加上 5。答案：1 3 5 7 9——每一个奇数数字，瞬间算出，全程没碰过一次阶乘。

练习 5（挑战题）：修改代码，同时判断黑板上的数能否被 6 整除。（提示：6 = 2 × 3，而你在这道题里已经知道怎么判断能不能被 2 和被 3 整除。）

能被 2 整除只需要最后一位是偶数——而这里每一位都是 d，所以就是要求 d 本身是偶数。能被 3 整除正是我们已经解决的问题：只要 n ≥ 3 就恒成立，或者（对更小的 n）看造出来的数的数字和。所以，能被 6 整除，当且仅当两个条件同时成立：

digits_with_six.py
import math

def solve(n, d):
    if n >= 6:
        divisors = {1, 3, 7, 9}
        if d == 5:
            divisors.add(5)
        divisible_by_6 = (d % 2 == 0)   # n>=6 时 3 已经自动成立
    else:
        m = math.factorial(n)
        number = int(str(d) * m)
        divisors = {x for x in [1,3,5,7,9] if number % x == 0}
        divisible_by_6 = (number % 6 == 0)
    return sorted(divisors), divisible_by_6
