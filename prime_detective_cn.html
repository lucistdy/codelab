案卷 01 / 08 入门线索

时钟上的秘密：什么是"取余"

先从一个你天天都在用的东西说起——时钟。

如果现在是 10 点，再过 5 个小时是几点？你肯定脱口而出：3 点。可是 10 + 5 明明等于 15 呀，为什么答案是 3？因为时钟上没有 15 点这种说法——每到 12，它就"绕回去"重新从 0 开始数。

这个"绕圈子、算余数"的动作，在数学和编程里有个正式名字，叫取余运算，符号是 %。它算的就是"除完之后剩下多少"：

算式意思结果
15 % 1215 除以 12，剩下几？3
7 % 37 除以 3，商 2 余几？1
20 % 520 除以 5，正好除尽0

用 Python 写一遍

clock.py
now_hour = 10
hours_to_add = 5
new_hour = (now_hour + hours_to_add) % 12
print(new_hour)   # 输出 3，因为 15 % 12 == 3
冷知识档案

Python 的取余和你想的一模一样贴心：-7 % 3 在 Python 里得到 2（永远不会是负数）。但在 C++ 这种语言里，-7 % 3 却会得到 -1！同一个算式，不同语言给的答案居然不一样——这就是为什么真正的程序员写代码前，都要先搞懂自己用的语言到底怎么"取余"的。

negative_mod.py
print(-7 % 3)     # 2 —— Python 的余数永远不是负数
print(-7 // 3)    # -3 —— // 是"整除"，结果向下取整
案卷 02 / 08 入门线索

循环游戏：时钟上的加法

取余运算最爱出现在所有"绕圈子"的场景里：星期、月份、游戏里的回合、密码本的字母表……

举个例子：今天是周三，100 天后是星期几？你不需要一天天数，只要把星期当成一个 7 格的时钟：

weekday.py
# 0 = 周日, 1 = 周一, 2 = 周二, 3 = 周三 ...
today = 3
days_later = 100
future_day = (today + days_later) % 7
print(future_day)   # 5，也就是 100 天后是周五！

是不是很神奇？100 天听起来要数很久，但取余运算一步就搞定了。这就是为什么程序员做"循环类"的题目——排班表、游戏回合、加密字母表——第一反应都是找一个合适的"时钟"（也就是 mod 后面的那个数字）。

侦探小贴士

凡是看到"每 N 个循环一次"的描述，脑子里就要立刻警铃大作：这题需要 mod N！比如"每 7 天一个星期""每 24 小时一天""每 26 个字母轮一圈的密码"，全都是同一种套路。

翻倍的超能力：快速幂

现在案子升级了。侦探社接到新任务：算出 2 的 1000000 次方，再对一个很大的数取余。直接一个一个乘，得算一百万次——电脑会算到天荒地老吗？其实不会，只要用对方法，连 30 步都不用。

秘诀就是"翻倍"。想象细胞分裂：1 变 2，2 变 4，4 变 8……每一步都是上一步的平方，只要 20 步左右就能超过一百万。这个技巧叫快速幂（二进制取幂）：把指数不断除以 2，每一轮把底数自己乘自己（平方），如果这一位是奇数就顺手把结果也乘上去。

fast_power.py
def fast_power(a, b, m):
    # 计算 (a 的 b 次方) % m，但不会真的算出那个巨大的数字
    result = 1
    base = a % m
    while b:                      # b 变成 0 就停下
        if b % 2 == 1:
            result = result * base % m
        base = base * base % m    # 这一步就是"翻倍"
        b = b // 2
    return result

print(fast_power(2, 1000000, 1000000007))
冷知识档案

其实 Python 早就把这个"翻倍超能力"内置好了，你甚至不用自己写：pow(a, b, m) 这个自带函数，第三个参数就是"顺便取余"，底层用的正是你刚学的快速幂技巧！后面案卷里我们会经常直接用它。

谁是质数？谁是伪装者？

好了，正式进入本案核心：质数。

质数是只能被 1 和它自己整除的数（并且要大于 1），比如 2、3、5、7、11、13……合数则是能被拆成更小数字相乘的"伪装者"，比如 91 = 7 × 13，看起来人畜无害，其实内部藏着两个"同伙"。

侦探社的头号任务，就是拿到一个数字，快速判断它到底是"清白的质数"，还是"藏了同伙的合数"。

侦探小贴士

1 既不是质数也不是合数——它太特殊了，数学家专门把它"请出局"，不参与这场游戏。

案卷 05 / 08 进阶调查

埃氏渔网：一网打尽所有质数

如果要找出 1 到 100 里所有的质数，古希腊数学家埃拉托斯特尼两千多年前就想出了一个超聪明的办法，后人叫它埃氏筛法——原理就像撒一张渔网，把"有同伙"的数字全部捞走，剩下的自然就是质数。

做法：从 2 开始，把 2 的所有倍数（4、6、8…）全部划掉，因为它们都有同伙 2；再看 3，把 3 的倍数全划掉；下一个没被划掉的就是质数，继续用它划掉它的倍数……一路撒网到 100，活下来的全都是真正的质数。

sieve.py
def sieve_of_eratosthenes(limit):
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False   # 0 和 1 直接出局
    for p in range(2, limit + 1):
        if is_prime[p]:
            # p 是质数，把它的倍数全部标记为合数
            for multiple in range(p * p, limit + 1, p):
                is_prime[multiple] = False
    return [n for n in range(limit + 1) if is_prime[n]]

print(sieve_of_eratosthenes(100))

这个方法特别快，找 100 万以内的所有质数，普通电脑一眨眼就能完成——比一个个去检查快得多。

案卷 06 / 08 硬核悬案

大数字怎么查？从蛮力搜查到聪明搜查

渔网法很棒，但如果只想知道一个超大的数字（比如 999999999989）是不是质数，撒一张能装下十亿个格子的网就太浪费了。这时候需要换一套审讯方法。

最直接的想法：拿 2、3、4、5……一路除到 n-1，只要有一个能整除，就抓到同伙了。

is_prime_slow.py
def is_prime_slow(n):
    if n == 0 or n == 1:
        return False
    for i in range(2, n):
        if n % i == 0:
            return False   # 抓到同伙了！
    return True

print(is_prime_slow(97))    # True

这样查一个百万级别的数，就要循环上百万次——对电脑来说还行，但如果数字有几十位长，这种"笨办法"就得算到天荒地老。这里有个聪明的省力技巧：

只要查到 √n 就够了。为什么？因为如果 n 能被拆成 a × b，那么 a 和 b 里一定至少有一个不超过 √n——想象两个人分一块地，两人不可能都比一半还大。所以只要在 2 到 √n 之间没找到同伙，n 就一定是清白的。

is_prime_fast.py
def is_prime_fast(n):
    if n == 0 or n == 1:
        return False
    for i in range(2, int(n ** 0.5) + 1):   # 只查到根号 n
        if n % i == 0:
            return False
    return True

print(is_prime_fast(999999937))   # True，而且几乎瞬间出结果

从"查到 n"变成"只查到 √n"，速度提升有多夸张？如果 n 是一亿，原来要循环一亿次，现在只要循环一万次——快了整整一万倍！

案卷 07 / 08 硬核悬案

费马测谎仪

但如果 n 不是一亿，而是几十位那么长呢？就算只查到 √n，也还是天文数字。侦探社需要一台"测谎仪"，不用挨个审问，靠几个"证人"就能大概率判断真假。

17 世纪数学家费马发现了一个神奇的规律，后人称为费马小定理：

费马小定理

如果 p 是质数，那么对任何一个和 p 没有公因数的数字 a（也就是"证人"），一定有：

ap−1 mod p = 1

反过来利用这个规律，就能做一台"测谎仪"：随便找几个证人 a，算一下 a 的 (n-1) 次方 mod n，如果结果不是 1，就百分之百抓到证据——n 绝对不是质数！

fermat_test.py
import random

def fermat_test(n, witness_count=5):
    if n == 0 or n == 1:
        return False
    for _ in range(witness_count):
        a = random.randrange(2, n - 1)      # 随机找一个证人
        if pow(a, n - 1, n) != 1:
            return False                     # 证人举报了，n 不是质数
    return True                              # 所有证人都放行，n 可能是质数

注意用词——费马测谎仪只能说"n 可能是质数"，不能百分百保证。这是因为它只有在抓到反例时才是铁证；如果证人们全部放行，还是有极小概率被骗过去。到底会不会被骗，接着往下看……

这类"完美骗子"被数学家称为卡迈克尔数（Carmichael Numbers）——它们的存在说明，费马测谎仪并不完美，我们需要一套更狠的盘问方式。

米勒-拉宾：多重盘问揭穿伪装

既然骗子能骗过一次测谎，那就多问几个刁钻问题。这就是 米勒-拉宾质数测试 的思路——除了看 a 的 (n-1) 次方，还要在算的过程中，检查一个更隐蔽的破绽。

关键的数学线索是这样的：

破案关键定理

如果 p 是质数，那么方程 x² ≡ 1 (mod p) 只有两个解：x = 1 或 x = p − 1（也就是 −1）。
换句话说：如果找到了第三个解，p 就绝对不是质数！

米勒-拉宾测试就是故意去找这个"第三个解"。具体步骤：

  1. 把 n − 1 拆成 u × 2ˡ（u 是奇数，相当于把偶数部分的 2 全部提出来）
  2. 找一个证人 a，算出 v = a 的 u 次方 mod n
  3. 把 v 反复平方，最多做 l 次
  4. 平方的过程中，如果 v 忽然从"不等于 ±1"的数变成了 1，说明抓到了那个"不该存在的第三个解"——铁证：n 不是质数
  5. 如果全程没有破绽，这个证人就放行，n 暂时算作"可能的质数"
miller_rabin.py
import random

def is_probably_prime(n, tries=8):
    if n == 0 or n == 1:
        return False
    for small_prime in [2, 3, 5, 7, 11, 13]:
        if n == small_prime:
            return True
        if n % small_prime == 0:
            return False

    # 第一步：把 n-1 拆成 u * 2^l
    u, l = n - 1, 0
    while u % 2 == 0:
        u = u // 2
        l = l + 1

    # 第二到五步：反复请证人来盘问
    for _ in range(tries):
        a = random.randrange(2, n - 1)
        v = pow(a, u, n)
        if v == 1 or v == n - 1:
            continue                 # 这位证人暂时没发现问题
        caught = False
        for _ in range(l - 1):
            v = v * v % n
            if v == n - 1:
                caught = False
                break
            caught = True
        if caught:
            return False              # 抓到破绽，n 不是质数
    return True                       # 所有证人都没抓到破绽

print(is_probably_prime(561))            # False —— 骗子被抓了！
print(is_probably_prime(999999999989))   # True，而且几乎瞬间出结果

米勒-拉宾测试对每一个骗子数字，最多只有 1/4 的证人会被骗过。这意味着只要多找几个证人（比如 8 个），骗过所有证人的概率会小到比你被闪电劈中还低——所以它被称为"概率性"测试，但在实际中几乎和确定性测试一样可靠。

结案花絮

顺带一提两个有趣的数论冷知识：像 31 这样的质数，倒过来读也是不同的质数（31 → 13），这种数叫 emirp（就是 prime 倒过来拼写）。而约数个数比所有比它小的数都多的数字，叫高合成数，也被叫做反质数——因为它简直是质数的对立面，浑身都是同伙。
