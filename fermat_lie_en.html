LEVEL 1

The problem: you can't interrogate every suspect

Back in Case 04, you learned the honest way to check if a number n is prime: try dividing it by every whole number up to √n. If nothing divides evenly, it's prime. Simple — and for small numbers, totally fine.

But real secret codes (the kind protecting your passwords online) use primes that are hundreds of digits long. For a number that big, √n is still a number with dozens of digits. Trying every possible divisor up to there wouldn't take minutes, or years — it would take longer than the universe has existed.

Why should you care?

Every time your phone connects to a secure website, it needs to find (or check) giant prime numbers, fast. If the only tool available was "try every divisor," the internet simply couldn't work at the speed it does. Detectives needed a shortcut — a way to get a confident answer without interrogating every single possible witness.

LEVEL 2

Fermat's strange, spooky pattern

In the 1600s, a mathematician named Pierre de Fermat noticed something odd about prime numbers and clock math (mod, the remainder trick from Case 01 — if you need a refresher, it's just "what's left over after dividing").

Here's the pattern. Pick a prime number, say p = 7. Now pick any other whole number a from 1 to 6 — it doesn't matter which one. Raise it to the power p − 1 (that's power 6), then take the remainder after dividing by 7. Watch what happens, every single time:

witness aa6a6 mod 7
111
2641
37291
44,0961
515,6251
646,6561

Every single witness lands on exactly 1. Not "close to 1," not "usually 1" — always, every time, no exceptions, for every prime number in the universe. Fermat proved this always happens whenever p is prime and a isn't a multiple of p. Mathematicians now call it Fermat's Little Theorem:

Fermat's Little Theorem

If p is prime, then for any number a (a "witness") that shares no common factor with p, it must be true that:

ap−1 mod p = 1

LEVEL 3

Flipping the rule into a lie detector

Here's the detective move: every real prime always obeys Fermat's rule. So — what happens if you test some mystery number n, and it breaks the rule?

The rule, if n really is prime

an−1 mod n always equals 1, for any witness a.

FLIP IT AROUND ↓

The catch, if n breaks the rule

If you find even one witness a where an−1 mod n is not 1, then n is guaranteed, 100%, no-question-about-it not prime.

This is the whole trick! You don't need to check every possible divisor. You just need to catch one witness telling on it. Grab a random number a, do the calculation, and if it doesn't equal 1, case closed — n is an impostor, not a real prime. This is exactly the same "if the rule is always true for real primes, and this one broke it, it can't be a real prime" logic detectives use to rule out suspects with an alibi that doesn't add up.

Cold Case File

There's one thing this trick can't do: if a witness doesn't catch anything (the result is 1), that's not proof n is prime — it just means this one witness didn't rat it out. Keep that thought, you'll need it in Level 6.

LEVEL 4

Building the lie detector in Python

Here's the real function from the case file. It calls in several random witnesses, one at a time, and only clears n if every single one of them fails to find anything suspicious.

fermat_test.py
import random

def fermat_test(n, witness_count=5):
    if n == 0 or n == 1:
        return False
    for _ in range(witness_count):
        a = random.randrange(2, n - 1)      # pick a random witness
        if pow(a, n - 1, n) != 1:
            return False                     # the witness blew the whistle -- n is not prime
    return True                              # every witness let it slide -- n is probably prime

LEVEL 6

The perfect impostor: Carmichael numbers

Remember the loose end from Level 3: passing the test doesn't prove a number is prime, it just means one witness didn't catch anything. Most of the time that's not a big deal — but a few numbers are professional con artists.

Wanted · 561

561 = 3 × 11 × 17 — a bona fide composite number that fools nearly every witness in the Fermat lie detector. For every witness a that shares no common factor with it, a560 mod 561 = 1 holds, acting exactly like a real prime.

Mathematicians call this breed of "perfect impostor" a Carmichael number. It's not that Fermat's theorem is wrong — it's that a Carmichael number has cleverly arranged its factors (in this case 3, 11, and 17) so that the disguise works against almost every possible witness. Try witness after witness, and it keeps passing — until, by pure bad luck for the impostor, you happen to pick a witness that is secretly one of its hidden factors (like a = 3, a = 11, or a = 17). That witness always catches it instantly, because a number can never disguise itself from one of its own factors.

Cold Case File

This is exactly why fermat_test uses several random witnesses instead of just one — and why real cryptography software doesn't rely on the Fermat test alone. Case 08 in the main file introduces the Miller–Rabin test, a tougher cross-examination that catches Carmichael numbers almost every time.

LEVEL 8

Quick challenges (no peeking until you've tried)

Work these out on paper (or in your head) before you check with the tool above.

Challenge 1: Use p = 5 (prime) and witness a = 2. Does Fermat's theorem hold?

We need 24 mod 5. 24 = 16, and 16 mod 5 = 1. Yes — exactly what the theorem promises, since 5 really is prime.

Challenge 2: Test n = 9 with witness a = 2. What does the lie detector conclude?

We need 28 mod 9. 28 = 256, and 256 mod 9 = 4 (since 9 × 28 = 252, leaving 4). Since 4 ≠ 1, witness a = 2 blows the whistle: 9 is not prime. Correct — 9 = 3 × 3.

Challenge 3: Why can the lie detector only ever say "probably prime," never "100% definitely prime," even when every witness passes?

Passing doesn't prove anything — it just means that particular witness didn't happen to catch anything. There's no way to rule out that a smarter impostor (a Carmichael number, like 561) is fooling every witness you happened to pick. Only a failing witness gives 100% proof — a passing witness is just one more vote of confidence.

Challenge 4: 561 = 3 × 11 × 17. In your own words, why do detectives call it a "perfect impostor"?

Because for almost every valid witness a (any a that doesn't happen to be 3, 11, or 17, or a multiple of them), a560 mod 561 comes out to exactly 1 — behaving just like a genuine prime would, even though 561 is clearly composite. It can pass interrogation after interrogation, right up until you get lucky and pick one of its own hidden factors as a witness.

Challenge 5 (use the tool above): Interrogate n = 341 with only witness 2. Then add witness 3 and re-run. What happened?

With just witness a = 2, 341 passes — 2340 mod 341 = 1 — even though 341 = 11 × 31 is composite! (341 is actually famous among mathematicians as the smallest number that fools witness 2 this way.) Add witness a = 3, though, and it gets caught immediately, since 3340 mod 341 ≠ 1. The lesson: never trust a single witness — the more (random) witnesses you call in, the smaller the chance any impostor slips through.
