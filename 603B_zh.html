模里的奶牛：有多少函数能在这条规则下幸存？

Farmer Ivan 的得意门生 Kevin Sun 被一条奇怪的规则难住了：定义在 0 到 p−1 之间的函数 f，必须对每一个 x 都满足 f(kx mod p) ≡ k·f(x) (mod p)。有些 f 能满足，大多数不能。Codeforces 603B 问的是：在所有可能的填表方式里，到底有多少个 f 能在这条规则下幸存？

写给爱思考的 13 岁少年 承接前几页的"回声"思想 可互动
第一关

认识这个任务

给你一个奇素数 p 和一个数 k（满足 0 ≤ k ≤ p−1）。想象你在造一张对照表——一个函数 f——把 {0, 1, …, p−1} 里的每一个数 x，都对应到 {0, 1, …, p−1} 里的某个输出 f(x)。只有当这张表对每一个范围内的 x 都满足下面这条规则时，它才算"合法"：

f(kx mod p) ≡ k · f(x)  (mod p)

说人话：任取一个输入 x，把它乘以 k 再对 p 取模，得到一个新的输入 kx mod p，那么表在这个新输入处的输出，必须等于原始输出乘以 k 之后再取模的结果。你的任务：数一数一共有多少张不同的合法表 f，答案对 1,000,000,007 取模。

题目原话

p=3, k=2 → 3 张合法的表。题目提示列出了全部三种：f = [0,1,2]、f = [0,2,1]、f = [0,0,0]（依次表示 f(0), f(1), f(2)）。
p=5, k=4 → 25 张合法的表。

为什么要在意速度？

p 最大可以到 1,000,000。光是填一张这么大的表，就有 pp 种可能的填法——一个天文数字，多到不可能一个一个去试。我们得想办法不用逐一检查，就能算出有多少张是合法的。

第二关

研究这三个幸存者

先来搞清楚，对于 p=3, k=2 而言，为什么这三张表都行得通——逐一检查每个 x。记住，我们需要 f(2x mod 3) ≡ 2f(x) (mod 3) 对 x = 0、1、2 都成立。

表 fx=0 检查x=1 检查x=2 检查
[0, 1, 2]f(0)=0 =2×0 ✓f(2)=2 =2×1 mod3=2 ✓f(1)=1 =2×2 mod3=1 ✓
[0, 2, 1]f(0)=0 =2×0 ✓f(2)=1 =2×2 mod3=1 ✓f(1)=2 =2×1 mod3=2 ✓
[0, 0, 0]f(0)=0 =2×0 ✓f(2)=0 =2×0 mod3=0 ✓f(1)=0 =2×0 mod3=0 ✓

注意到每一张表都有一个共同点：f(0) 永远是 0。再看另外两项——不管你给 f(1) 选了什么值，f(2) 的值就完全被决定了（要么和 f(1) 相等，要么翻倍，要么被规律强行锁定）。就好像 1 和 2 被链条拴在一起，而 0 是独自一人。这正是我们接下来要挖掘出来的结构。

第三关

先解决两个简单的特殊情况

在攻克一般情况之前，先把 k 的两个边界值解决掉。

如果 k = 1：规则变成 f(x) ≡ f(x) (mod p)——不管怎样都恒成立！没有任何限制，所以 f 可以是任意函数：每一个输入都可以对应到 p 个输出中的任意一个，一共 pp 张合法的表。

如果 k = 0：那么对每一个 x，kx mod p = 0 都成立，规则变成对每个 x 都有 f(0) ≡ 0 × f(x) = 0 (mod p)。这其实只是同一条限制重复了 p 次：f(0) = 0。其余的输出，f(1) 到 f(p−1)，完全自由——一共 pp−1 张合法的表。

最重要的一句话

k=1：零限制，pp 张表。k=0：一条限制（f(0)=0），pp−1 张表。那介于两者之间的每一个 k 呢？

第四关

一般情况：乘以 k 是一台回声机器

现在假设 2 ≤ k ≤ p−1。因为 p 是素数，k 又不是它的倍数，所以"乘以 k（再对 p 取模）"这个操作其实是一次洗牌：它把非零数字 1, 2, …, p−1 重新排列了一遍，绝不会有两个数落在同一个位置上。而且，就像数字谜题页面里 10 的幂的规律、以及Jzzhu 的回声机器里的数列一样，反复乘以 k 最终总会回声回到出发点——每一个非零数字都属于某个不断重复的循环。

让我们对 p=5, k=4 亲眼见证这一幕。从 1 出发，不断乘以 4 并对 5 取模：

出发
1
→×4
1×4 mod5
4
↻回声！
4×4 mod5
1

这是一个长度为 2 的循环：{1, 4}。那从 2 出发呢？

出发
2
→×4
2×4 mod5
3
↻回声！
3×4 mod5
2

又是一个长度为 2 的循环：{2, 3}。于是全部四个非零数字，1 到 4，恰好整整齐齐分成了两个长度为 2 的循环。那 0 呢？0 × 4 = 0，所以不管 k 是多少，0 永远独自待在自己的、长度为 1 的循环里。

案卷线索

这个循环长度有个正式的名字：k 模 p 的乘法阶——满足 kL ≡ 1 (mod p) 的最小正整数 L。这和数字谜题页面里"要走多少步才能回声回到起点"的周期为 6 那个问题，本质上是同一个问题，只不过每次的 k 和 p 不一样罢了。

第五关

为什么每个循环恰好值 p 种选择

这里是关键的一步。任选一个非零数字组成的循环，比如我们例子里的 {1, 4}。规则告诉我们 f(4) = f(1×4 mod5) ≡ 4×f(1) (mod 5)——所以一旦你选定了 f(1)，f(4) 的值就完全被强制决定了。你没法单独再去选它。

那这个循环到底给了我们多少自由选择呢？恰好一个——不管我们给 f(1) 选什么，一共有 p 种可能的取值（0 到 p−1）。一旦 f(1) 定下来，规则就会沿着整个循环一路走下去，自动帮你算出其余每一个值。而且，因为这个循环恰好在 L 步之后完美地回声回到 1（这正是阶 L 的定义！），走到终点时永远不会出现矛盾——被强制推出来的这一串值，最终一定会绕回来，和你最初的选择完全吻合。

那孤零零的循环 {0} 呢？规则在那里说的是 f(0) ≡ k×f(0) (mod p)，整理一下就是 (k−1)×f(0) ≡ 0 (mod p)。因为 p 是素数，而这里 k ≠ 1（k=1 的情况我们已经单独处理过了），所以 k−1 不是 p 的倍数，这就强行把 f(0) = 0 定为唯一合法的选择。零自由度——正好和我们在第二关手算出来的结果一致！

最重要的一句话

每个非零循环都贡献一个因子 p（自由选一个值，其余全被强制决定）。{0} 这个循环贡献一个因子 1（毫无自由度）。把所有循环的因子乘在一起，就恰好不重不漏地数完了每一张合法的表。

第六关

数一数循环的个数

p−1 个非零数字会分成长度全都相同的循环，长度就是 L（也就是 k 的乘法阶）。所以非零循环的个数，就是 (p−1) / L。结合第五关"每个非零循环贡献一个因子 p"：

答案 = p(p−1)/L  （对 1,000,000,007 取模）

用 p=5, k=4 来验证一下：我们发现 L=2（两个长度为 2 的循环），所以 (p−1)/L = 4/2 = 2，得到 5² = 25。和题目给出的答案完全一致！

第七关

逐行读代码

下面是完整的解法。先看左边的代码，再看右边的大白话翻译。

moodular.py
MOD = 1000000007

p, k = map(int, input().split())

if k == 0:
    print(pow(p, p - 1, MOD))
elif k == 1:
    print(pow(p, p, MOD))
else:
    L = 1
    cur = k % p
    while cur != 1:      # 沿着回声一路走，直到落回 1
        cur = (cur * k) % p
        L += 1
    print(pow(p, (p - 1) // L, MOD))
if k == 0: print(pow(p, p - 1, MOD)) elif k == 1: print(pow(p, p, MOD))
第三关的两个特殊情况，直接用 Python 的快速取模幂 pow 处理。
L = 1 cur = k % p while cur != 1: cur = (cur * k) % p L += 1
用最直接的方式找出循环长度（乘法阶）：不断乘以 k 再对 p 取模，一直走到落回 1 为止。因为 p ≤ 1,000,000，这个循环最多跑一百万次——瞬间搞定。
print(pow(p, (p - 1) // L, MOD))
第六关方框里的公式：把 p 提升到"非零循环个数"这个次方，用快速取模幂运算算出来。

第十关

练习题：先自己算，再用工具核对

每一题都先在纸上算一遍，再用上面的小工具验证答案。

练习 1：p=7, k=6。注意到 6 ≡ −1 (mod 7)。−1 的阶是多少？答案又是多少？

(−1)¹ = −1 ≠ 1，但 (−1)² = 1。所以阶是 L=2。非零循环个数：(7−1)/2 = 3。答案：7³ = 343。

练习 2：p=7, k=2。手动追踪一下从 1 出发的循环（不断乘以 2 并对 7 取模，直到回声回到 1）。

1 → 2 → 4 → 8 mod7=1。一共走了 3 步，所以 L=3。非零循环个数：(7−1)/3=2。答案：7² = 49。（这两个循环分别是 {1,2,4} 和 {3,6,5}——验证一下：3×2=6，6×2=12mod7=5，5×2=10mod7=3，正好回声！）

练习 3：p=11, k=10。用练习 1 的同一个技巧——10 ≡ −1 (mod 11)。不借助计算机求出答案。

(−1)²=1，所以又是 L=2。非零循环：(11−1)/2=5。答案：11⁵ = 161051。

练习 4（挑战题）：p=1,000,003（一个较大的素数），k=1。答案是多少？为什么完全不用做任何找循环的操作就能瞬间给出答案？

k=1 正是第三关的特殊情况——规则不施加任何限制，所以任意函数都合法。答案直接就是 pp mod 1{,}000{,}000{,}007，只需要调用一次快速取模幂运算。完全不需要走什么循环，因为压根没什么可追踪的——一旦 k=1，每个输入都是它自己那个长度为 1 的、平凡的"循环"。

练习 5（挑战题）：修改代码，让它在 2 ≤ k ≤ p−1 时，除了答案之外，还打印出 L（也就是 k 的阶）。
moodular_with_order.py
MOD = 1000000007

p, k = map(int, input().split())

if k == 0:
    print(pow(p, p - 1, MOD))
elif k == 1:
    print(pow(p, p, MOD))
else:
    L = 1
    cur = k % p
    while cur != 1:
        cur = (cur * k) % p
        L += 1
    print(pow(p, (p - 1) // L, MOD), "(order L =", L, ")")
