城堡守卫谜题：在奇形怪状的棋盘上摆棋子

一座歪歪扭扭、形状古怪的城堡需要 k 名守卫。每名守卫都能看到自己所在的整行和整列，任何守卫都不能站在别的守卫看得见的地方。一共有多少种不同的安排方法？我们一步步解决这道经典竞赛题，还要揪出它示例代码里藏着的五个 bug。

适合 13 岁+ 回溯 捉 bug 互动棋盘 8 道练习题
第 1 关

谜题是什么

先用大白话把题目说清楚。

题目（POJ 1321 棋盘问题）

给你一个能放进 n × n 方框（n ≤ 8）的棋盘。不是每个格子都属于棋盘：# 表示真正的棋盘格，. 表示空洞，什么都不能放。要在真正的格子上摆 k 个完全相同的棋子（k ≤ n），要求任意两个棋子不能在同一行或同一列。求所有不同摆法的数量。

如果你会下国际象棋，就会认出这种棋子：它和车（♜）一模一样，沿着行和列攻击。所以问题其实是：在这块破破烂烂的棋盘上，有多少种方法放 k 个车，让它们互相攻击不到？

先试最小的例子。棋盘是 2 × 2，只有两个真格子，要放 k = 1 个棋子：

带斜纹的格子是空洞。只放一个棋子，有两个真格子可选，所以答案是 2。

再看一座 4 × 4 的城堡，要放 k = 4 名守卫。每一行、每一列都必须正好有一名守卫，而真格子排成了一条斜线：

每一行只有一个真格子，根本没得选：答案是 1。

"完全相同"很重要

棋子长得一模一样，所以交换两个棋子不算新的摆法，只有用了哪些格子才重要。记住这一点，因为它决定了程序该怎么搜索。

第 3 关

一行一行地想

两个棋子不能同行，所以每一行最多放一个棋子。这就给了我们一个清爽的计划：从上往下一行一行走，每行只做一个决定。

选项 A
跳过这一行
这一行不放棋子，直接去下一行。k 可能比 n 小，所以必须有这个选项。
选项 B
放一个棋子
选一列：它必须是真格子（#），而且这一列还没被别的棋子占用。
什么时候停
放满 k 个
这就是一种合法摆法：计数！如果行先用完了，就是死路。

为了记住哪些列被占了，我们用一个由 True/False 组成的列表 cols_used。这又是回溯的模板：做选择（占一列）→ 往下走（去下一行）→ 撤销选择（释放这一列，让别的分支还能用）。

下面是第一组样例（#. / .#，k = 1）的完整搜索树。dfs(row, placed) 的意思是"现在在第 row 行，已经放了 placed 个棋子"：

放满 k 个 → 计数 +1行用完了 → 死路
小测验：为什么我们总是去下一行，从不回到前面的行？

因为棋子是完全相同的。如果允许先在第 1 行放一个棋子，再回到第 0 行放，就会用不同的顺序拼出同一组格子，把它数两次。严格地从上往下走，每种摆法就只有唯一一种搭建顺序，所以正好被数一次。

这是修好的程序。逻辑和原来完全一样，我们只是把搜索放进 solve()，并修掉了所有 bug：

chessboard.py（修复版）
def solve(n, k, board):
    ans = 0
    cols_used = [False] * n               # 哪些列已经有棋子了

    def dfs(row, placed):
        nonlocal ans                       # ✅ ans 属于 solve()
        if placed == k:                    # ✅ 用 == 比较
            ans += 1                        # 放满 k 个：又多一种！
            return
        if row == n:                       # 行用完了：死路
            return
        dfs(row + 1, placed)                # 选项 A：跳过这一行
        for col in range(n):                # 选项 B：在这一行放一个棋子
            if board[row][col] == '.' or cols_used[col]:
                continue                    # 是空洞，或者这一列已被占用
            cols_used[col] = True          # 做选择  ✅ cols_used[col]
            dfs(row + 1, placed + 1)        # 往下走
            cols_used[col] = False         # 撤销选择

    dfs(0, 0)
    return ans

while True:
    n, k = map(int, input().split())
    if (n, k) == (-1, -1):
        break
    board = [input() for _ in range(n)]
    print(solve(n, k, board))

附加陷阱：输入里的空行

有些评测系统会在两组测试之间放一个空行。这时 input().split() 返回空列表，程序会崩溃：ValueError: not enough values to unpack。更安全的做法是一次读入全部输入，再逐个单词处理，因为 split() 会完全忽略空行：

robust_input.py（替换 while 循环）
import sys

def main():
    data = sys.stdin.read().split()    # 输入里的所有单词，空行被忽略
    pos = 0
    while True:
        n, k = int(data[pos]), int(data[pos + 1])
        pos += 2
        if n == -1 and k == -1:
            break
        board = data[pos:pos + n]        # 接下来的 n 个单词就是棋盘的各行
        pos += n
        print(solve(n, k, board))

main()
# 2
# 1

第 7 关

剪枝：别追不可能的梦

设想还要放 5 个棋子，却只剩 3 行了。每行最多放一个，这绝对不可能成功，可我们的程序还在继续探索！

多加一行就能解决：如果 placed + 剩下的行数 < k，立刻放弃。我们来数一数，在完整的 8 × 8 棋盘、k = 8 时，加和不加这一行，dfs 分别被调用多少次：

pruning.py
def solve_counted(n, k, board, prune):
    ans = calls = 0
    cols_used = [False] * n

    def dfs(row, placed):
        nonlocal ans, calls
        calls += 1
        if placed == k:
            ans += 1
            return
        if row == n:
            return
        if prune and placed + (n - row) < k:
            return                     # ✂ 剩下的行不够了
        dfs(row + 1, placed)
        for col in range(n):
            if board[row][col] == '.' or cols_used[col]:
                continue
            cols_used[col] = True
            dfs(row + 1, placed + 1)
            cols_used[col] = False

    dfs(0, 0)
    return ans, calls

full = ["#" * 8] * 8
print(solve_counted(8, 8, full, prune=False))   # (40320, 1952457)
print(solve_counted(8, 8, full, prune=True))    # (40320, 178882)
1,952,457
不剪枝时的调用次数
178,882
只加一行剪枝：工作量少了约 11 倍，答案还是 40,320
为什么差这么多？

当 k = n 时，每一行都必须放一个棋子，所以"跳过这一行"的分支永远没希望。不剪枝的话，程序会沿着每一条跳过分支一直走到底才发现。剪枝检查则会立刻察觉，马上掉头。

第 8 关

大数字，以及为什么还得搜索

在完整的棋盘（没有空洞）上，其实可以用公式算。我们看看公式是怎么来的。

取一个完整的 n × n 棋盘，k = n。第 0 行有 n 列可选，第 1 行有 n − 1 列（有一列被占了），第 2 行有 n − 2 列……所以总数是 n × (n − 1) × … × 1 = n!（"n 的阶乘"）。

n12345678
n!126241207205,04040,320

k 更小时也有公式：从 n 行里选 k 行，从 n 列里选 k 列，再把它们一一配对，有 k! 种配法。完整的 8 × 8 棋盘、k = 4 时，就是 70 × 70 × 24 = 117,600。

但空洞会打破所有公式

棋盘一旦有了空洞，漂亮的乘法就不灵了，因为每一行能用的列都不一样。这正是题目要我们搜索的原因。n ≤ 8 时，回溯已经足够快。棋盘更大时，程序员会把它和动态规划结合起来：记住"当前行 + 已用的列 + 已放的棋子数"，同样的局面就不用再算第二次。练习题第 8 题就让你亲手实现！

检查站

概念小测验

先在脑子里想好答案，再点开看。

Q1. 如果删掉 dfs(row + 1, placed) 这一行（"跳过这一行"的选项），会出什么问题？

那样一来，走到的每一行都必须放一个棋子，只有 k = n 时才对。对样例 1（k = 1），程序会在第 0 行放一个棋子就结束，永远找不到只用第 1 行的那种摆法，会输出 1 而不是 2。

Q2. 如果忘了写 cols_used[col] = False（撤销选择那一步）呢？

列一旦被用过，就永远保持"已占用"，哪怕我们已经退出了那个分支。后面的分支会误以为这些列被挡住了，于是很多合法摆法找不到，结果偏小。

Q3. 为什么 if placed == k 要写在 if row == n 前面？

如果最后一个棋子放在最后一行，我们会调用 dfs(n, k)。这时两个条件都成立，而我们要的是计数，不是把它当死路扔掉。先检查 placed == k 还能让我们在 k 个棋子放完时立刻停下，不必再走完剩下的行。

def show_all(n, k, board):
    cols_used = [False] * n
    pieces = []                              # 每个棋子的 (row, col)

    def dfs(row):
        if len(pieces) == k:
            for r in range(n):
                line = list(board[r])
                for pr, pc in pieces:
                    if pr == r:
                        line[pc] = "O"
                print("".join(line))
            print()
            return
        if row == n:
            return
        dfs(row + 1)
        for col in range(n):
            if board[row][col] == '.' or cols_used[col]:
                continue
            cols_used[col] = True; pieces.append((row, col))
            dfs(row + 1)
            pieces.pop(); cols_used[col] = False

    dfs(0)

6. 城堡里的皇后 ★★★

把棋子升级成皇后：两个棋子不能同行、同列，也不能在同一条斜线上。在有形状的棋盘上数一数。（检验：完整 8 × 8、k = 8 → 92，就是著名的八皇后答案；样例 1、k = 2 → 0。）

💡 提示

记住每个棋子的位置。两个格子 (r1, c1) 和 (r2, c2) 在同一条斜线上，当且仅当 abs(r1 - r2) == abs(c1 - c2)。

✅ 参考答案
ex6_queens.py
def solve_queens(n, k, board):
    ans = 0
    cols_used = [False] * n
    pieces = []

    def diagonal_free(r, c):
        return all(abs(pr - r) != abs(pc - c) for pr, pc in pieces)

    def dfs(row, placed):
        nonlocal ans
        if placed == k:
            ans += 1
            return
        if row == n:
            return
        dfs(row + 1, placed)
        for col in range(n):
            if board[row][col] == '.' or cols_used[col] or not diagonal_free(row, col):
                continue
            cols_used[col] = True; pieces.append((row, col))
            dfs(row + 1, placed + 1)
            pieces.pop(); cols_used[col] = False

    dfs(0, 0)
    return ans

print(solve_queens(8, 8, ["#" * 8] * 8))   # 92
print(solve_queens(2, 2, ["#.", ".#"]))    # 0   (两个格子在同一条斜线上)

7. 用二进制位表示列 ★★★

用一个整数 used 代替 cols_used 列表：第 c 位是 1，就表示第 c 列被占了。附加题：为什么不再需要"撤销选择"那一行了？

💡 提示

如果 used & (1 << c) 不为零，第 c 列就被占了。把 used | (1 << c) 传给下一层调用。这是一个新的数，你自己的 used 从没被改过，就像回溯那一课里的 code + letter。

✅ 参考答案
ex7_bits.py
def solve_bits(n, k, board):
    ans = 0

    def dfs(row, placed, used):
        nonlocal ans
        if placed == k:
            ans += 1
            return
        if row == n:
            return
        dfs(row + 1, placed, used)
        for col in range(n):
            if board[row][col] == '#' and not used & (1 << col):
                dfs(row + 1, placed + 1, used | (1 << col))   # 新的数：不用撤销

    dfs(0, 0, 0)
    return ans

print(solve_bits(2, 1, ["#.", ".#"]))                      # 2
print(solve_bits(4, 4, ["...#", "..#.", ".#..", "#..."]))   # 1

8. 记住，别重复（DP） ★★★

把搜索改成一个返回剩余棋盘摆法数的函数 ways(row, placed, used)，再加上 @lru_cache，让重复出现的局面只算一次。在 300 个随机棋盘上和（第 7 题的）solve_bits 对比检验。

💡 提示

还是那三种情况：placed == k 返回 1；row == n 返回 0；否则把"跳过"分支和每个合法的"放置"分支加起来。答案只取决于 (row, placed, used)，这就是缓存能起作用的原因。

✅ 参考答案
ex8_memo.py
import random
from functools import lru_cache

def solve_memo(n, k, board):
    @lru_cache(maxsize=None)
    def ways(row, placed, used):
        if placed == k:
            return 1
        if row == n:
            return 0
        total = ways(row + 1, placed, used)                   # 跳过这一行
        for col in range(n):
            if board[row][col] == '#' and not used & (1 << col):
                total += ways(row + 1, placed + 1, used | (1 << col))
        return total
    return ways(0, 0, 0)

random.seed(2026)
ok = True
for _ in range(300):
    n = random.randint(1, 6)
    k = random.randint(1, n)
    board = ["".join(random.choice("#.") for _ in range(n)) for _ in range(n)]
    ok = ok and solve_memo(n, k, board) == solve_bits(n, k, board)
print(ok)                                   # True
print(solve_memo(8, 8, ["#" * 8] * 8))      # 40320
