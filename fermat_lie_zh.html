费马测谎仪

在正式案卷里，这个技巧几段话就带过去了。这里我们把它重新讲一遍——放慢节奏，用小数字打比方，请出那个真实存在的"通缉犯"，外加一个可以让你亲自审问嫌疑人的小工具。

不需要高深数学 用到快速幂（案卷 03） 可交互
第一关

难题：不可能挨个审问所有嫌疑人

在案卷 04 里，你学过判断一个数 n 是不是质数的老实办法：用从 2 到 √n 的每一个整数去试除。只要没有一个能整除，它就是质数。简单直接——数字小的时候完全没问题。

但真正的加密系统（保护你的密码和聊天记录的那种）用的质数常常有几百位数字那么长。这么大的数字，它的 √n 也依然是个几十位的天文数字。把它所有可能的除数都试一遍，不是要花几分钟或者几年，而是要比宇宙存在的时间还要长。

这跟你有什么关系？

每次手机连上一个安全网站，背后都要飞快地找到（或者验证）巨大的质数。如果唯一的办法只有"挨个试除"，互联网根本不可能跑得这么快。侦探们需要一条捷径——不用审问每一个可能的证人，也能给出足够可信的结论。

第二关

费马发现的诡异规律

17 世纪，数学家皮埃尔·德·费马发现了质数和"钟表数学"（也就是 mod，案卷 01 里讲过的余数把戏——如果忘了，它就是"除完之后剩下多少"）之间一个奇怪的规律。

规律是这样的：随便挑一个质数，比如 p = 7。再随便挑一个从 1 到 6 的整数 a——挑哪个都无所谓。把它算到 p − 1 次方（也就是 6 次方），再除以 7 取余数。看看每次会发生什么：

证人 aa6a6 mod 7
111
2641
37291
44,0961
515,6251
646,6561

每一个证人都恰好落在 1 上。不是"接近 1"，也不是"大多数时候是 1"——而是每一次、毫无例外，对宇宙里任何一个质数都成立。费马证明了：只要 p 是质数，并且 a 不是 p 的倍数，这个规律就一定成立。后人把它叫做费马小定理：

费马小定理

如果 p 是质数，那么对任何一个和 p 没有公因数的数字 a（也就是"证人"），一定有：

ap−1 mod p = 1

第三关

把规律反过来，变成一台测谎仪

这里是侦探的关键一步：任何真正的质数永远遵守费马的规律。那么——如果我们审问一个神秘数字 n，结果它违反了这条规律，会怎么样？

规律：如果 n 真的是质数

an−1 mod n 永远等于 1，不管选哪个证人 a。

反过来想 ↓

破绽：如果 n 违反了规律

只要你找到哪怕一个证人 a，使得 an−1 mod n 不等于 1，那么 n 百分之百、毫无悬念不是质数。

这就是整个诀窍！你不需要检查每一个可能的除数，只需要抓到一个证人举报它。随便找个数字 a 算一算，如果结果不是 1，案子就结了——n 是个冒牌货，不是真正的质数。这跟侦探常用的逻辑一模一样："真凶的不在场证明永远说得通；这个人的不在场证明说不通；所以他不可能是真凶。"

冷案档案

但这招也有做不到的事：如果某个证人没有抓到任何破绽（结果确实是 1），这并不能证明 n 是质数——只能说明这一个证人没举报而已。记住这句话，第六关会用到。

第四关

用 Python 搭建这台测谎仪

下面是案卷里的真实代码。它会随机请来好几位证人，一个接一个盘问，只有当每一位证人都没查出问题时，才会放行 n。

fermat_test.py
import random

def fermat_test(n, witness_count=5):
    if n == 0 or n == 1:
        return False
    for _ in range(witness_count):
        a = random.randrange(2, n - 1)      # 随机找一个证人
        if pow(a, n - 1, n) != 1:
            return False                     # 证人举报了，n 不是质数
    return True                              # 所有证人都放行，n 可能是质数

当场抓包：n = 15

我们手动审问一下 n = 15（我们已经知道它是 3 × 5，绝对不是质数），用证人 a = 2。需要算的是 214 mod 15，用的是案卷 03 里那套"平方再翻倍"的算法。

第六关

完美骗子：卡迈克尔数

还记得第三关留下的伏笔吗：测试通过并不能证明一个数是质数，只能说明这一位证人没查出问题。大多数时候这不是什么大事——但有那么几个数字，是职业骗子。

通缉令 · 561

561 = 3 × 11 × 17——一个不折不扣的合数，却能骗过费马测谎仪的几乎所有证人。对每一个和它没有公因数的证人 a，都满足 a560 mod 561 = 1，表现得和真正的质数一模一样。

数学家把这种"完美骗子"叫做卡迈克尔数。这不是说费马定理错了——而是卡迈克尔数恰好把自己的因数（这里是 3、11、17）安排得非常巧妙，让这套伪装几乎能骗过所有可能的证人。换一个证人再试，它照样过关——直到某次，冒牌货运气不好，你恰好挑中了它自己藏起来的一个因数（比如 a = 3、a = 11 或 a = 17）当证人。那位证人会立刻抓到它，因为一个数字永远没办法在自己的因数面前伪装。

冷案档案

这正是 fermat_test 要请来好几位随机证人、而不是只问一个的原因——也是真正的加密软件不会只依赖费马测试的原因。主案卷案卷 08 会介绍Miller–Rabin 测试，一套更狠的盘问方式，几乎每次都能抓到卡迈克尔数这种冒牌货。

第七关

轮到你来审问了

挑一个嫌疑数字 n，再列出一批想盘问的证人（用逗号隔开）。这个工具会运行和上面 Python 代码完全一样的费马判定，同时也会用老实、缓慢的办法再核实一遍，让你看看测谎仪判断得对不对。

费马测谎仪

先试试默认值——561 就是案卷里那个头号通缉犯。然后把证人换成包含 3、11 或 17 的组合，看它最终是怎么被抓到的。还可以审问一下：97（一个诚实的质数）、91 = 7×13（很容易被抓到）、以及 341 = 11×31（先只用证人 2 试一次，再加上证人 3……）。
第八关

小测验（先自己做，别急着看答案）

用纸笔（或者心算）先做一遍，再用上面的工具核对答案。

题目 1：用 p = 5（质数）和证人 a = 2。费马小定理成立吗？

需要算 24 mod 5。24 = 16，16 mod 5 = 1。成立——正如定理承诺的那样，因为 5 真的是质数。

题目 2：用证人 a = 2 测试 n = 9，测谎仪会得出什么结论？

需要算 28 mod 9。28 = 256，256 mod 9 = 4（因为 9 × 28 = 252，剩下 4）。由于 4 ≠ 1，证人 a = 2 当场举报：9 不是质数。判断正确——9 = 3 × 3。

题目 3：为什么就算每一位证人都放行，测谎仪也只能说"可能是质数"，不能说"百分百确定是质数"？

放行并不能证明什么——只能说明这位证人恰好没抓到破绽。没有办法排除有更聪明的冒牌货（比如卡迈克尔数 561）刚好骗过了你挑的所有证人。只有举报才是百分百的铁证；放行只是又多了一票信任而已。

题目 4：561 = 3 × 11 × 17。用你自己的话说说，为什么侦探们叫它"完美骗子"？

因为对几乎每一个合法的证人 a（只要不是 3、11、17 或它们的倍数），a560 mod 561 都恰好等于 1——表现得和真正的质数一模一样，尽管 561 明明是合数。它能一次又一次通过审讯，直到你运气好，挑中了它自己藏起来的某个因数当证人。

题目 5（用上面的工具）：只用证人 2 审问 n = 341，然后再加上证人 3 重新运行。发生了什么？

只用证人 a = 2 时，341 通过了测试——2340 mod 341 = 1——尽管 341 = 11 × 31 明明是合数！（341 在数学家中很有名，是能骗过证人 2 的最小数字。）但只要加上证人 a = 3，它立刻就露馅了，因为 3340 mod 341 ≠ 1。教训是：永远别只信一个证人——请来的（随机）证人越多，冒牌货蒙混过关的可能性就越小。
