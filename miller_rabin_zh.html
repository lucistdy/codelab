米勒–拉宾 交叉盘问法

费马测谎仪能抓住几乎所有骗子——除了那些职业惯犯。这里我们把破解它们的后续追问技巧重新讲一遍：放慢节奏，用小数字打比方，外加一个可以让你亲自审问嫌疑人的小工具。

第一关

测谎仪的破绽

在费马测谎仪（案卷 07）里，你学过一个快速抓假质数的招数：随便找一个证人 a，检查 an−1 mod n 是不是等于 1。如果不是，n 就一定有罪。

但你也见过那个几乎每次都能骗过这招的惯犯：561（= 3 × 11 × 17），一个卡迈克尔数。证人 2、5、7、13 全都为它作证。事实上，几乎所有证人都会为它作证。光靠费马测试，根本分不清它和真质数的区别。

侦探的下一步

如果嫌疑人能顶住一次测谎，别放弃——追问一个更刁钻的问题。这正是米勒–拉宾测试的思路。它依然会检查 an−1 mod n，但在计算的过程中，它还会检查一个卡迈克尔数根本藏不住的、更隐蔽的破绽。

第二关

一种新线索：1 的平方根

先问一个听起来有点奇怪的问题：在一个有 n 个刻度的钟表上，哪些数字 x 满足 x2 mod n = 1？换句话说，哪些数字"平方一圈之后正好绕回 1"？

先检查 1 到 6，对 7（真正的质数）取模：

这次有四个数字落在 1 上：1、4、11、14。1 和 14（= 15 − 1）是你预期中"正常"的两个。但 4 和 11 是多出来的——它们本不该平方之后等于 1。它们的存在，本身就是 15 不可能是质数的证据（当然，我们早就知道了）。

规律

真正的质数永远只有两个 1 的平方根：1 和 n − 1。合数则可能藏着多出来的"非法"平方根。找到一个 1 的非法平方根，是比费马判定还要隐蔽的一种揭穿假货的办法——这正是米勒–拉宾能抓住卡迈克尔数的关键。

第三关

破案关键定理

定理

如果 p 是质数，那么方程 x2 ≡ 1 (mod p) 恰好有两个解：x = 1 或 x = p − 1。

为什么这个规律永远成立？这是关于质数最有用的一个事实，说起来比听起来简单：如果一个质数能整除两个数的乘积，它一定能整除其中至少一个数——不可能"两边各分一点责任"。因为 x2 − 1 可以分解成 (x − 1)(x + 1)，如果质数 p 能整除这个乘积，它就必须完全整除 (x − 1)，或者完全整除 (x + 1)——于是只能得到 x = 1 或 x = p − 1，没有别的可能。合数不遵守这条规则，这正是 15 能藏进 4 和 11 这两个多余骗子的原因。

反过来想 ↓

抓骗子的规则

如果你在检查一个神秘数字 n，找到了 x2 ≡ 1 (mod n) 的第三个解——某个既不是 1 也不是 n − 1 的 x——那么 n 百分之百，绝对不是质数。没有例外，连卡迈克尔数也逃不掉。

第四关

把线索变成算法

所以我们要去找 1 的非法平方根。巧妙的地方在这里：我们不需要挨个去查每一个数字——它们其实**免费藏**在案卷 03 那套算 an−1 mod n 的"重复平方"计算过程里。

  1. 把 n − 1 拆成 u × 2l（u 是奇数——把偶数部分的 2 全部提出来）。
  2. 找一个证人 a，算出 v = au mod n。
  3. 把 v 反复平方，最多做 l 次——每平方一次，指数就翻一倍，这样 v 就会一步步从 au 走到 au·2l = an−1。
  4. 如果 n 真是质数，费马定理保证这条链最后一个值必须是 1。所以在链条的某个地方，它一定第一次从"不是 1"变成"是 1"。根据第三关的定理，那次变化前一步的数值只能是 1 或 n − 1。如果是别的数——那就是非法平方根，铁证 n 不是质数。
  5. 如果全程没有任何破绽，这个证人就放行，n 暂时算作"可能的质数"。
miller_rabin.py
import random

def is_probably_prime(n, tries=8):
    if n == 0 or n == 1:
        return False
    for small_prime in [2, 3, 5, 7, 11, 13]:
        if n == small_prime:
            return True
        if n % small_prime == 0:
            return False

    # 第一步：把 n-1 拆成 u * 2^l
    u, l = n - 1, 0
    while u % 2 == 0:
        u = u // 2
        l = l + 1

    # 第二到五步：反复请证人来盘问
    for _ in range(tries):
        a = random.randrange(2, n - 1)
        v = pow(a, u, n)
        if v == 1 or v == n - 1:
            continue                 # 这位证人暂时没发现问题
        caught = False
        for _ in range(l - 1):
            v = v * v % n
            if v == n - 1:
                caught = False
                break
            caught = True
        if caught:
            return False              # 抓到破绽，n 不是质数
    return True                       # 所有证人都没抓到破绽

print(is_probably_prime(561))            # False —— 骗子被抓了！
print(is_probably_prime(999999999989))   # True，而且几乎瞬间出结果
u, l = n - 1, 0 while u % 2 == 0: u = u // 2 l = l + 1
不断把 n−1 除以 2，直到它变成奇数，同时数一数除了几次——这个次数就是 l，剩下的就是 u。这样 n−1 = u × 2l。
v = pow(a, u, n) if v == 1 or v == n - 1: continue
算出这条链上的第一个检查点。如果它已经是合法的平方根（1 或 n−1），暂时没什么可疑的——直接进入下一轮平方，或者换下一位证人。
for _ in range(l - 1): v = v * v % n if v == n - 1: caught = False break caught = True
沿着剩下的链条走，一路平方。一旦 v 变成 n−1，那就是一个合法的检查点——立刻放行这位证人。如果一路走完都没碰到 n−1，caught 就一直保持 True——说明 v 中途"非法"直接跳到了 1（或者压根没到过 1）。
if caught: return False
找到了一个非法平方根——案子结了，n 不是质数，不用再问其他证人了。

冷案档案

整套诀窍一句话就能说清：米勒–拉宾算的是和费马一模一样的幂，但它不只看最终答案，还会检查沿途每一块"垫脚石"平方根——卡迈克尔数可以伪造最终答案，但没办法把每一块垫脚石都伪造好。

第六关

为什么它几乎不可能被骗过

数学家证明了一个很了不起的结论：对任何一个骗子数字，米勒–拉宾测试最多只有 1/4 的证人会被骗过（对比一下费马测试，卡迈克尔数几乎能骗过所有证人）。这意味着只要多请几位证人，风险就会急速下降。

只要请来 8 位证人（就是上面代码的默认值），全部被骗过的概率已经比你被闪电劈中的概率还低。这就是为什么米勒–拉宾测试在数学上被称为"概率性"测试——但在实际使用中，真实的软件（包括密码学系统）都把它当作几乎确定可靠的答案来用。

第八关

小测验（先自己做，别急着看答案）

先自己想一遍，再用上面的工具核对答案。

题目 1：把 n = 13 的 n − 1 写成 u × 2l 的形式。

n − 1 = 12。不断除以 2：12 → 6 → 3（3 是奇数，停止）。一共除了 2 次，剩下 3。所以 u = 3，l = 2，验证一下：3 × 22 = 3 × 4 = 12。✓

题目 2：对 11（真正的质数）取模，1 到 10 里哪些 x 满足 x² ≡ 1 (mod 11)？

只有 x = 1（因为 12 = 1）和 x = 10（因为 102 = 100 = 9 × 11 + 1）。正好两个解——完全符合第三关那条定理的预言，因为 11 真的是质数。

题目 3：用你自己的话说说，为什么找到 1 mod n 的第三个平方根，就能证明 n 不是质数？

因为第三关的定理说，真正的质数只能恰好有两个数字平方后等于 1：1 和 n − 1。如果你找到了其他数字也平方等于 1，说明 n 违反了每一个真质数都毫无例外遵守的规则——所以 n 不可能是真正的质数。这和费马测试"把永远成立的规律反过来用"的逻辑一模一样，只不过用在了一个更隐蔽、更难伪造的线索上。

题目 4（用上面的工具）：用证人 2、3、7 交叉盘问 n = 1105 = 5 × 13 × 17。发生了什么？和你在纯费马测试里看到的有什么不同？

1105 也是一个卡迈克尔数——它几乎能完全骗过纯费马测试，跟 561 一样。但米勒–拉宾抓住了每一位证人（2、3、7 都在链条中暴露出了非法平方根）。故事和 561 一模一样：最终的费马答案可以被伪造，但通往那个答案的每一块垫脚石都会出卖它。

题目 5（硬核，不用工具）：案卷里的代码打印 is_probably_prime(999999999989)，几乎瞬间就给出了答案。相比试除法，为什么这个 12 位数的大小几乎不影响速度？

米勒–拉宾的每一步——把 n−1 里的 2 提出来，以及计算每一个 au mod n——都靠的是案卷 03 的快速幂技巧，只需要大约 log2(n) 次平方，而不是 n 次。对一个 12 位数来说，每位证人也就大约 40 次平方，乘上几位证人，总共几百次乘法而已——比起把它拿去试除几十亿个候选数，快得多。
