哈密顿的环球旅行：正十二面体上的哈密顿回路

1857 年，爱尔兰数学家威廉·罗恩·哈密顿爵士发明了一个谜题，不久后伦敦的一家游戏公司把它当作玩具出售。它的棋盘是一个正十二面体：20 个顶点，每个代表一座城市。挑战是：每座城市恰好去一次，最后回到出发地。今天，这样的环游路线叫作哈密顿回路，它直通计算机科学里最大的未解之谜之一。

适合 13 岁+ 图论 3D 模型 可玩的谜题 8 道练习题
第 1 关

认识正十二面体

"Dodeca" 在希腊语里是"十二"，"hedron" 是"面"。正十二面体由 12 个完全相同的正五边形组成，每个顶点处都有三个五边形相交。

拖动模型让它转起来。虚线是背面的棱。

20 个顶点 · 30 条棱 · 12 个五边形面

正十二面体是仅有的五种完美正多面体之一，它们叫作柏拉图立体。每一种的所有面都是相同的正多边形，每个顶点看起来也都一模一样：

立体面的形状F（面）V（顶点）E（棱）
正四面体三角形446
正方体正方形6812
正八面体三角形8612
正十二面体五边形122030
正二十面体三角形201230
一个神奇的公式

对每一种柏拉图立体，都有 V − E + F = 2。正十二面体：20 − 30 + 12 = 2。这就是欧拉公式，它对任何没有洞的立体都成立。练习题第 1 题会让你把五种都验证一遍。

不用数也能数出来

棱不必一条条去数。12 个五边形，每个 5 条边，一共 60 条，但每条棱被 2 个面共用，所以 60 ÷ 2 = 30 条棱。同理，五边形的角一共有 12 × 5 = 60 个，立体的每个顶点处有 3 个角相交，所以 60 ÷ 3 = 20 个顶点。

第 2 关

把它压扁：从立体到地图

想象正十二面体是橡皮做的。在正面戳一个洞，把洞口使劲撑大，再把整个东西压平。顶点和棱都保留下来，你就得到了一张地图。

数学家把这样的图叫作图（graph）。这可不是数据图表，这里它的意思是：

顶点
一座城市
图上的点。正十二面体有 20 个，哈密顿用从 B 到 Z 的 20 个辅音字母给它们命名。
边
一条道路
连接两座城市的线。一共 30 条。
度
每座城市的道路数
数一数一座城市连着几条路。在正十二面体上，每座城市都正好有 3 条。

地图的外边界就是我们撑开的那个面。数一数五边形：地图里面 11 个，加上外面那一个，正好 12 个。在 Python 里，图很容易用邻接表来存：每座城市对应一个邻居列表。我们把城市编号为 0–19（B = 0，C = 1，……，Z = 19）：

dodecahedron.py
NAMES = "BCDFGHJKLMNPQRSTVWXZ"      # 哈密顿的 20 个城市字母

def dodecahedron():
    adj = {v: [] for v in range(20)}
    def road(a, b):                    # 一条双向道路
        adj[a].append(b)
        adj[b].append(a)
    for i in range(5):
        road(i, (i + 1) % 5)              # 外圈五边形
        road(i, 5 + 2 * i)                # 外侧辐条
        road(6 + 2 * i, 15 + i)           # 内侧辐条
        road(15 + i, 15 + (i + 1) % 5)    # 内圈五边形
    for j in range(10):
        road(5 + j, 5 + (j + 1) % 10)     # 中间 10 个城市围成的环
    return adj

adj = dodecahedron()
print(len(adj))                                    # 20  座城市
print(sum(len(roads) for roads in adj.values()) // 2)   # 30  条道路
print(sorted(set(len(r) for r in adj.values())))     # [3]  每座城市都有 3 条路
print(adj[0])                                    # [1, 5, 4]  B 的邻居：C、H、G

为什么要除以 2？每条路会出现在两个列表里，两端各一次。这又是"握手"的小窍门。

第 3 关

哈密顿的谜题

哈密顿的挑战：从任意一座城市出发，沿着道路走，每座城市恰好去一次，最后回到起点。

哈密顿回路
每座城市一次，再回家
一次环游。这就是哈密顿的谜题。
哈密顿路径
每座城市一次
不用回家。这个更容易，因为回路去掉最后一条路就是一条路径。
欧拉回路
每条路一次
这是另一个谜题！城市可以重复经过，但每条路必须恰好走一次。
别把欧拉和哈密顿搞混

比哈密顿早大约 120 年，莱昂哈德·欧拉解决了著名的柯尼斯堡七桥问题，并找到一条关于道路谜题的简单规则：想要每条路恰好走一次并回到起点，每座城市的道路数都必须是偶数。正十二面体上每座城市有 3 条路，是奇数，所以欧拉回路不可能存在。欧拉的问题有这样简单的判断方法；而哈密顿的问题，你会看到，没有。

odd = [city for city in adj if len(adj[city]) % 2 == 1]
print(len(odd))   # 20  → 20 座城市全是奇数，所以没有欧拉回路

第 5 关

教 Python 来玩

电脑的玩法和你一模一样：选一条路，继续走，卡住了就退回来试下一条路。这就是回溯：做选择 → 往下走 → 撤销选择。

find_trip.py（使用第 2 关的 adj 和 NAMES）
def hamilton_cycle(adj, start=0):
    n = len(adj)
    path = [start]
    visited = {start}

    def explore(city):
        if len(path) == n:                    # 每座城市都去过了……
            return start in adj[city]         # ……还有路回家吗？
        for nxt in adj[city]:
            if nxt not in visited:
                path.append(nxt); visited.add(nxt)      # 做选择
                if explore(nxt):                       # 往下走
                    return True
                path.pop(); visited.remove(nxt)         # 撤销选择
        return False

    return path if explore(start) else None

第 6 关

一共有多少种不同的旅行？

别找到第一条就停下，我们把所有路线都数出来。唯一的改动：不再返回 True，而是给计数器加 1。

count_trips.py（使用第 2 关的 adj）
def count_cycles(adj, start=0):
    n = len(adj)
    path = [start]
    visited = {start}
    count = 0

    def explore(city):
        nonlocal count
        if len(path) == n:
            if start in adj[city]:
                count += 1
            return
        for nxt in adj[city]:
            if nxt not in visited:
                path.append(nxt); visited.add(nxt)
                explore(nxt)
                path.pop(); visited.remove(nxt)

    explore(start)
    return count

trips = count_cycles(adj)
print(trips)         # 60
print(trips // 2)    # 30
60
从 B 出发的旅行（两个方向都算）
30
真正不同的环游路线
为什么要除以 2？

每一条环游路线都可以朝两个方向走：B → C → … → H → B 和 B → H → … → C → B 走的是完全相同的路。程序把两者都数了，所以真正不同的回路是 60 ÷ 2 = 30 条。起点也无所谓：无论从哪里"开始"，回路都会经过 B，所以把 B 固定为起点不会漏掉任何一条。

第 7 关

哈密顿的密码：左与右

哈密顿是个代数天才，他想出了一个不用地图就能描述旅行的绝妙方法。

走到任何一座城市，你都会看到正好两条不是刚走过来的路：一条在你的左手边，一条在你的右手边。所以整个旅行可以写成一串字母：L 表示"走左手边那条路"，R 表示"走右手边那条路"。哈密顿围绕这些走法建立了一整套代数，叫作 Icosian Calculus（二十面体演算）。

这是一次完整旅行的密码。从 B 出发走到 C，然后按这 20 个字母走：

LLLRRRLRLRLLLRRRLRLR

注意，它是同一个 10 字母图案 LLLRRRLRLR 重复两次！在上面的游戏里点按哈密顿的密码走，看看效果。要在 Python 里按密码走，我们得知道哪条路在哪一边：利用每座城市在地图上的位置，把它的三条路按方向逆时针排好：

left_right.py（使用第 2 关的 adj 和 NAMES）
import math

def position(v):                              # 城市 v 在地图上的位置
    if v < 5:
        angle, r = 90 - 72 * v, 200                  # 外圈五边形
    elif v < 15:
        angle, r = 90 - 36 * (v - 5), (140 if v % 2 == 1 else 105)   # 中间的环
    else:
        angle, r = 54 - 72 * (v - 15), 55            # 内圈五边形
    a = math.radians(angle)
    return r * math.cos(a), r * math.sin(a)

def around(v):                                # v 的 3 条路，逆时针排列
    x, y = position(v)
    return sorted(adj[v], key=lambda w: math.atan2(position(w)[1] - y, position(w)[0] - x))

def follow(code, start, first):
    route = [start, first]
    for turn in code:
        here, came_from = route[-1], route[-2]
        ring = around(here)
        k = ring.index(came_from)
        # 背对来路站着：顺时针方向的那条就是左手边的路
        route.append(ring[(k - 1) % 3] if turn == "L" else ring[(k + 1) % 3])
    return route

route = follow("LLLRRRLRLR" * 2, 0, 1)
print(" ".join(NAMES[c] for c in route))
# B C D F G R Q P N M L K J T V W X Z S H B C
print(len(set(route[:20])))     # 20    → 20 座城市，每座一次
print(route[20:] == [0, 1])     # True  → 回到 B，又朝着 C 走去

转了 20 次之后，我们回到了 B，又朝 C 走去，和出发时一模一样。这正是 Python 在第 5 关找到的那条路线！

本页最惊人的事实

一共有 30 条不同的环游路线，可是每一条的密码都是 LLLRRRLRLR 重复两次。区别只在于从密码的哪个位置开始读，以及路线是不是镜像（所有 L 和 R 互换）。正十二面体对称得不可思议：说到底，它只有一条哈密顿回路，只是从不同角度去看。

不信？让 Python 检查全部 60 条路线
check_code.py（使用上面的 adj 和 around()）
def all_cycles(adj, start=0):
    n, path, visited, found = len(adj), [start], {start}, []
    def explore(city):
        if len(path) == n:
            if start in adj[city]:
                found.append(path[:])
            return
        for nxt in adj[city]:
            if nxt not in visited:
                path.append(nxt); visited.add(nxt)
                explore(nxt)
                path.pop(); visited.remove(nxt)
    explore(start)
    return found

def turns(trip):                     # 一条路线的 L/R 密码
    code = ""
    for i in range(len(trip)):
        came_from, here, going = trip[i - 1], trip[i], trip[(i + 1) % len(trip)]
        ring = around(here)
        k = ring.index(came_from)
        code += "L" if ring[(k - 1) % 3] == going else "R"
    return code

PATTERN = "LLLRRRLRLR" * 2
MIRROR = PATTERN.translate(str.maketrans("LR", "RL"))

def same_code(code):                 # 是 PATTERN 或其镜像的某个旋转吗？
    return code in PATTERN + PATTERN or code in MIRROR + MIRROR

trips = all_cycles(adj)
print(len(trips))                                  # 60
print(all(same_code(turns(t)) for t in trips))      # True
第 8 关

为什么哈密顿的谜题其实很难

欧拉的谜题有个立竿见影的判断法：数数每座城市的道路数。哈密顿的谜题有这样简单的判断法吗？

你可能会猜："只要每座城市都有 3 条路，像正十二面体那样，就一定有环游路线。"来认识一下彼得森图。它有 10 座城市，每座城市正好 3 条路，看起来非常友好：

petersen.py（使用第 6 关的 count_cycles）
petersen = {v: [] for v in range(10)}
for i in range(5):
    for a, b in ((i, (i + 1) % 5),           # 外圈五边形
                 (i, i + 5),                 # 辐条
                 (i + 5, (i + 2) % 5 + 5)):   # 内部五角星
        petersen[a].append(b)
        petersen[b].append(a)

print(sorted(set(len(r) for r in petersen.values())))   # [3]  每座城市 3 条路
print(count_cycles(petersen))                           # 0    一条环游路线都没有！

零！每座城市的道路数和正十二面体一样，却没有哈密顿回路。所以"处处 3 条路"什么也证明不了。事实上，150 多年过去了，还没有人找到任何对所有地图都管用的快速判断法。

一个价值百万美元的问题

计算机科学家把哈密顿的谜题归入一类著名的问题，叫作 NP 完全问题。检查一条给定的路线很容易（练习题第 2 题），但找出一条似乎需要一场随地图变大而爆炸式增长的搜索。没有人确切知道是否存在快速的方法。这就是 P 与 NP 问题，解决它的人能拿到 100 万美元奖金。

真实的程序怎么应对
  • 尽早剪掉死路：如果某座没去过的城市只剩不到 2 个"没去过或是路线端点"的邻居，它就永远没法被穿过，立刻退回。
  • 聪明的顺序：先试最受限制（空闲道路最少）的城市。
  • 记住已做的工作：对"已访问城市的集合"做动态规划（见动态规划），可以精确处理大约 20–25 座城市。

哈密顿回路也藏在真实问题里：快递路线、电路板钻孔、DNA 测序，问的都是"每样东西去一次，而且要高效"。

检查站

概念小测验

先在脑子里想好答案，再点开看。

Q1. 一条路线把每条路恰好走了一次。它是哈密顿回路吗？

不一定！那是欧拉回路。哈密顿的规则说的是城市：每座恰好一次。欧拉回路可能多次经过同一座城市。在正十二面体上，欧拉回路根本不存在（所有度数都是奇数），但哈密顿回路存在。

Q2. 程序从 B 出发找到了 60 条路线，为什么说只有 30 条不同的回路？

每条回路都被找到两次，两个方向各一次（顺时针和逆时针）。它们用的是同一组道路，所以算作一条：60 ÷ 2 = 30。

Q3. 彼得森图的每座城市都有 3 条路，和正十二面体一样。为什么它没有哈密顿回路？

因为每座城市的道路数决定不了答案，关键在于道路怎样连接。彼得森图"拧"得很巧妙，每一次尝试都会被困住：搜索试遍了所有可能，一条也找不到。这正是哈密顿的谜题难的原因，它没有欧拉那样简单的计数规则。

2. 路线检查员 ★

写一个函数 is_hamilton_cycle(adj, route)：只有当路线恰好经过每座城市一次，并且每一步（包括最后回家的那一步）都沿着道路走时，才返回 True。检查很容易，虽然寻找很难！

💡 提示

两项检查：sorted(route) == sorted(adj)（每座城市恰好一次）；以及对每个 i，route[(i + 1) % n] 都在 adj[route[i]] 里。

✅ 参考答案
ex2_inspector.py
def is_hamilton_cycle(adj, route):
    if sorted(route) != sorted(adj):          # 每座城市恰好一次？
        return False
    for i in range(len(route)):
        a, b = route[i], route[(i + 1) % len(route)]
        if b not in adj[a]:                   # a → b 有路吗？
            return False
    return True

good = [0, 1, 2, 3, 4, 13, 12, 11, 10, 9, 8, 7, 6, 15, 16, 17, 18, 19, 14, 5]
print(is_hamilton_cycle(adj, good))                            # True
print(is_hamilton_cycle(adj, good[:-1] + [6]))                 # False  (城市 6 出现两次)
print(is_hamilton_cycle(adj, good[:5] + good[6:] + [good[5]]))   # False  (4 → 12 没有路)

3. 正方体上的环游 ★★

正方体有 8 个顶点。把它们编号为 0–7，写成二进制（000 到 111）时，每一位分别表示左/右、下/上、前/后。两个顶点之间有棱，当且仅当它们只有一位二进制数字不同。建出正方体的图，数一数它的哈密顿回路。

💡 提示

翻转一位二进制数字就是异或运算：v 的邻居是 v ^ 1、v ^ 2、v ^ 4。然后用 count_cycles，再除以 2。

✅ 参考答案

4. 路径与回路：小房子 ★★

"小房子"图是一个正方形（0-1-2-3）加一个屋顶（城市 4 连着 2 和 3）。数一数它的哈密顿路径（起点终点任意）和哈密顿回路。别忘了方向要除以 2！

💡 提示

数路径时，把每座城市都当一次起点；每当路径走满 5 座城市就加一（不用回家）。每条路径会被找到两次，两端各一次。

✅ 参考答案
ex4_house.py
house = {0: [1, 3], 1: [0, 2], 2: [1, 3, 4], 3: [0, 2, 4], 4: [2, 3]}

def count_paths(adj):
    n, total = len(adj), 0
    for start in adj:
        path, visited = [start], {start}
        def explore(city):
            nonlocal total
            if len(path) == n:
                total += 1
                return
            for nxt in adj[city]:
                if nxt not in visited:
                    path.append(nxt); visited.add(nxt)
                    explore(nxt)
                    path.pop(); visited.remove(nxt)
        explore(start)
    return total

print(count_paths(house) // 2)    # 7   条哈密顿路径
print(count_cycles(house) // 2)   # 1   条哈密顿回路：0-1-2-4-3-0

Icosian Game 附带的谜题里，有一道给出了前五座城市，要你把旅行补完。如果你的路线必须以 B C D F G 开头（绕外圈五边形一圈），有几种方法补完？把它们打印出来。

💡 提示

✅ 参考答案

def finish_trip(adj, prefix):
    n, path, visited, found = len(adj), list(prefix), set(prefix), []
    def explore(city):
        if len(path) == n:
            if path[0] in adj[city]:
                found.append(path[:])
            return
        for nxt in adj[city]:
            if nxt not in visited:
                path.append(nxt); visited.add(nxt)
                explore(nxt)
                path.pop(); visited.remove(nxt)
    explore(path[-1])
    return found

ways = finish_trip(adj, [0, 1, 2, 3, 4])

petersen = {v: [] for v in range(10)}
for i in range(5):
    for a, b in ((i, (i + 1) % 5), (i, i + 5), (i + 5, (i + 2) % 5 + 5)):
        petersen[a].append(b)
        petersen[b].append(a)

def hamilton_path(adj, start):
    path, visited = [start], {start}
    def explore(city):
        if len(path) == len(adj):
            return True                     # 不用回家
        for nxt in adj[city]:
            if nxt not in visited:
                path.append(nxt); visited.add(nxt)
                if explore(nxt):
                    return True
                path.pop(); visited.remove(nxt)
        return False
    return path if explore(start) else None

7. 骑士巡游 ★★★

国际象棋的马走"日"字。它能从 5 × 5 棋盘的一个角出发，每个格子恰好踩一次吗？这其实是乔装打扮的哈密顿路径问题：格子是城市，马的走法是道路。找出一条巡游路线，再数一数从角上出发一共有多少条。

💡 提示

走到哪个格子，就把步数（1–25）写进去；撤销选择时改回 0。数出全部路线要花一两秒。

✅ 参考答案
ex7_knight.py
MOVES = [(1, 2), (2, 1), (2, -1), (1, -2), (-1, -2), (-2, -1), (-2, 1), (-1, 2)]

def knight_tours(n, count_all):
    board = [[0] * n for _ in range(n)]
    found, first = 0, None
    def jump(r, c, step):
        nonlocal found, first
        board[r][c] = step                           # 做选择
        if step == n * n:
            found += 1
            first = first or [row[:] for row in board]
        else:
            for dr, dc in MOVES:
                nr, nc = r + dr, c + dc
                if 0 <= nr < n and 0 <= nc < n and board[nr][nc] == 0:
                    jump(nr, nc, step + 1)          # 往下走
                    if first and not count_all:
                        break
        board[r][c] = 0                               # 撤销选择
    jump(0, 0, 1)
    return found, first

_, tour = knight_tours(5, count_all=False)
for row in tour:
    print(row)
# [1, 14, 19, 8, 25]
# [6, 9, 2, 13, 18]
# [15, 20, 7, 24, 3]
# [10, 5, 22, 17, 12]
# [21, 16, 11, 4, 23]
print(knight_tours(5, count_all=True)[0])   # 304  条从角上出发的巡游路线

8. 网格城市：什么时候能环游？ ★★★

城市排成 m × n 的网格，上下左右相邻的城市之间有路。把 2 × 2 到 5 × 5 的每种网格都测试一遍，看看有没有哈密顿回路，找出规律。再解释为什么会这样。

💡 提示

像国际象棋棋盘那样给网格涂色。每条路都连接一座黑城市和一座白城市，所以环游路线必然黑、白、黑、白……交替。这说明路线上城市的总数有什么特点？

✅ 参考答案
ex8_grids.py
def grid(m, n):
    return {(r, c): [(r + dr, c + dc) for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1))
                     if 0 <= r + dr < m and 0 <= c + dc < n]
            for r in range(m) for c in range(n)}

def has_cycle(adj):
    start = next(iter(adj))
    path, visited = [start], {start}
    def explore(city):
        if len(path) == len(adj):
            return start in adj[city]
        for nxt in adj[city]:
            if nxt not in visited:
                path.append(nxt); visited.add(nxt)
                if explore(nxt):
                    return True
                path.pop(); visited.remove(nxt)
        return False
    return explore(start)

for m in range(2, 6):
    print(m, [has_cycle(grid(m, n)) for n in range(2, 6)])
# 2 [True, True, True, True]
# 3 [True, False, True, False]
# 4 [True, True, True, True]
# 5 [True, False, True, False]

规律：当且仅当 m × n 是偶数时存在环游路线。原因：回路黑、白、黑、白……交替，两种颜色的城市用得一样多，所以城市总数必须是偶数。如果 m × n 是奇数，经过所有城市的回路就不可能存在。（当 m × n 是偶数时，总可以沿着各列上下蛇形前进，再沿边缘返回。）
